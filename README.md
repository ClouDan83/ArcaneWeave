# Arcane Waves

Gioco fantasy survival Android di Daniele Falamesca / Bazaverse.

Questa repository contiene il progetto Android standard usato per le build di test di Arcane Waves.

- Package: `com.bazaverse.arcanewaves`
- Min SDK: 23
- Target/Compile SDK: 36
- Java: 17
- Gameplay: ondate infinite, mostri casuali, magie automatiche, monete e potenziamenti illimitati.
